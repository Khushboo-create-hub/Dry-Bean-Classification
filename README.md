# Dry Bean Classification

## Project Overview

This project is part of the Machine Learning Assignment.

The objective is to implement and compare five machine learning classification algorithmsnusing the UCI Dry Bean dataset.

## Dataset

Source: UCI Machine Learning Repository

Dataset: Dry Bean Dataset

Total original instances: 13,611

Instances after duplicate removal: 13,543

Input features: 16

Target variable: Class

Classification type: Multiclass (7 classes)

## Machine Learning Models

1. Logistic Regression
2. Decision Tree
3. K-Nearest Neighbors
4. Gaussian Naive Bayes
5. Support Vector Machine

## Project Status

Dataset inspection and preprocessing completed.

Model implementation and evaluation in progress.
